지역 변수와 매개변수, return 값이 여기 들어가는 대표주자들, 스택 프래임(stack frame)이라는 주소로 호출

컵 형태인 만큼 크기가 정해져있고 그보다 더 많이 저장하면 갈곳을 잃은 데이터는 넘쳐흘러 오류를 일으킨다, 하지만 그렇다고 다른데 저장할수도 없는게, 그러면 보안 위협이 생긴다

함수에서 잠깐만 빌려쓰는 공간인 만큼 함수가 끝나면 빌렸던 주소 안의 데이터는 전부 사라진다, 잘 생각해보니 진짜로 지역도 매게도 리턴값도 다 안받아주고 따로 뭐 안붙이면 사라진다, 스택에 저장되는거라 그렇게 된거구나
